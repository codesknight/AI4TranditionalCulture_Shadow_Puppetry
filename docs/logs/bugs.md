# Bug 排查日志

## BUG-001：超出范围时手臂被拉长

- 日期：2026-11-17；关联 `REQ-002`、`DEV-002`。
- 现象：动作目标超出臂长允许范围时，前臂长度随目标变化。
- 复现：基线代码的肩点 `(460,252)` 与左手目标 `(310,295)` 的距离超过其两段各 75 的总臂长 150；旧算法约束了用于求肘角的距离，却继续用未约束的原始手部坐标绘制前臂。
- 根因：求解与绘制使用不同的目标，未对最终手部位置施加可达约束。
- 修复：`solveArm` 将不可达目标投影到可达圆，统一返回肩、肘、手坐标；当前造型臂长统一配置为每段 85。
- 回归：遍历全部动作和时间样本，断言两段臂长固定；额外覆盖超远目标与肩手重合边界。
- 状态：计算层修复并通过自动回归；视觉表现待人工验收。

## BUG-002：逐帧替换手柄节点影响焦点

- 日期：2026-11-17；关联 `REQ-002`、`DEV-002`。
- 现象：旧渲染函数每次重建 `handles.innerHTML`，焦点所在交互节点会被移除；动画中聚焦手柄可能丢失焦点。
- 排查证据：基线 `render` 在每帧对整个手柄容器写入 HTML，而不是更新既有节点。此问题由代码路径确认，未伪称完成浏览器复现。
- 修复：只在初始化创建手柄，之后仅更新 `transform`、`aria-valuenow` 及容器可见性；SVG 交互容器由 `img` 改为 `group`，手柄采用 `slider` 语义。
- 回归：控制器测试确认键盘调整、动画和显示切换后节点引用不变，容器 HTML 仅写入一次。
- 状态：代码与节点身份回归通过；真实浏览器焦点和辅助技术验证待完成。

## BUG-003：解构参数函数体内的严格模式声明导致语法失败

- 日期：2026-11-17；关联 `DEV-002`，本轮开发中发现，未发布。
- 复现：首次运行新增 `npm run verify`，`node --check` 报 `Illegal 'use strict' directive in function with non-simple parameter list`。
- 根因：具有解构参数的工厂函数内部声明了 `'use strict'`，不符合 JavaScript 语法规则。
- 修复：将严格模式声明移动到各文件顶层。
- 回归：全部 JavaScript 语法检查和 13 项自动测试通过，构建成功。
- 状态：已修复。
