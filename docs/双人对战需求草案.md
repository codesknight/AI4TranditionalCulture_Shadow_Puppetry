# 双人影武对决需求草案

记录日期：2026-11-17。用户要求保留本方案；当前仅进入待办，不在西游主题版本中实现。

## 方向

两位玩家各操纵一个皮影武生，在公共影幕上对战。先做本地同屏，再考虑联网；同时保留“双人摆影竞速”作为较轻量的备选玩法。

## 建议玩法（待开发与调优）

- 左右移动、跳跃，使用签杆调整武器方向与姿态。
- 攻击、按朝向格挡、消耗体力的蓄力破防。
- 三局两胜、每局 60 秒；生命值与体力限制连续攻击。
- 命中停顿、震动、火花和击退反馈。
- 本地键盘分区输入，并预留手柄支持。

以上数值与具体键位属于方案建议，尚未作为最终平衡参数验收。

## 架构约束

- 将单影偶场景扩展为 `puppets / players` 集合，每人拥有自己的签杆。
- `combat.js` 负责攻击范围、命中、格挡、伤害及击退；按攻击编号去重，避免每帧重复扣血。
- `players.js` 负责玩家与输入配置，`match.js` 负责回合及胜负。
- 签杆/动画/渲染与战斗判定分离。
- 对战先固定公共光源、幕面和角色深度，保持画面与碰撞一致；争夺灯光可作为后续特殊模式。
- 在线版增加房间与同步，由服务器权威判定血量、命中和胜负。

关联需求：REQ-006。本草案不代表双人模式已经完成。
