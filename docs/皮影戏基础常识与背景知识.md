# 皮影戏基础常识与背景知识

整理日期：2026 年 11 月 17 日。本文以中国皮影戏为主，供入门阅读与项目背景参考；地方名称、材料和表演习惯存在差异，不宜把某一地区的做法视为全国统一标准。

## 1. 皮影戏是什么

皮影戏也称“影子戏”“灯影戏”，是用皮革或纸等材料制成平面影偶，由艺人操纵杆件，借助灯光和影幕呈现人物动作，并配合演唱、说白和音乐讲述故事的传统戏剧。它把造型、雕刻、操偶、说唱和器乐结合在同一场演出中。[来源：中国非遗网《皮影戏概述》](https://www.ihchina.cn/art/detail/id/18619.html)

观看时可以同时关注三个层面：影偶如何活动，唱腔如何叙事，音乐如何配合人物情绪和动作。只看静态影人，难以了解这门艺术的全部面貌。

## 2. 起源与历史背景

- **起源尚无确考**：汉武帝思念李夫人、请术士招魂的故事，是常见的起源传说，不足以证明成熟皮影戏诞生于汉代。
- **宋代已有明确记载**：宋人的笔记记下了影戏演出与艺人活动，说明当时影戏已相当成熟。南宋孟元老的《东京梦华录》记述的是北宋都城汴梁的生活，不要将作者生活年代与书中场景混淆。
- **明清地方特色逐渐突出**：各地在唱腔、造型和操纵技巧上形成不同风格，出现以地域命名的皮影戏种类。

因此，介绍历史时宜采用“历史悠久，宋代已有成熟演出记载”的表述；“始于汉、兴于唐、盛于宋”应注明属于流传说法。[来源：中国非遗网《中国皮影戏》](https://www.ihchina.cn/Article/Index/detail?id=11504)

## 3. 一场演出如何完成

基本空间关系可理解为：

```text
光源 → 影偶与操纵杆 → 透光影幕 → 观众
             ↑
       艺人在幕后操纵
```

影偶位于光源与影幕之间，艺人在幕后控制动作；音乐和演唱与影像共同完成叙事。皮影并非只能呈现黑色轮廓，彩色影偶也是其重要特征。联合国教科文组织的介绍指出，影偶可以用皮革或纸制作，相关技艺常通过家庭、戏班与师徒关系传承。[来源：UNESCO 皮影戏影像介绍](https://www.unesco.org/archives/multimedia/document-2233)

艺人可能兼顾操偶、演唱和演奏，也可能由多人分工。部分艺人能同时操纵多个影偶、变换嗓音或即兴演唱，所以幕后协作同样值得观看。[来源：中国非遗网 2022 年专题](https://www.ihchina.cn/project_details/26209)

## 4. 影人怎样制作

传统皮制影人常使用牛皮、驴皮或羊皮。典型制作环节包括处理皮料、绘制图样、雕镂、着色，以及连接部件、安装操纵杆。影人通常由头部、躯干和四肢等部分组合，通过活动连接实现动作；桌椅、建筑、动物和其他景物也可制作成演出部件。

常见结构是在身体与双手处设置操纵杆，但具体结构会随地区和表演需要变化。“皮影”也不意味着影偶一定是皮制品，例如湖南皮影中多见纸偶。[来源：中国非遗网《皮影戏概述》](https://www.ihchina.cn/art/detail/id/18619.html)

## 5. 地方特色举例

下表用于认识差异，不是完整流派名录。

| 地区或种类 | 入门辨识点 |
| --- | --- |
| 河北唐山皮影戏 | 影人常用驴皮；唱腔以乐亭方言为基础，具有板腔体特色。 |
| 陕西华县皮影戏 | 以碗碗腔为代表，唱腔细腻婉转。 |
| 陕西华阴老腔 | 声音高亢有力，常见一人领唱、众人帮腔。 |
| 浙江海宁皮影戏 | 造型侧重彩绘，与当地蚕桑民俗联系紧密，有“蚕花戏”传统。 |
| 湖南皮影戏 | 多使用纸偶，角色行当细分，重视动作和人物性格。 |

这些差异说明，地方方言、民间音乐、生活习俗和制作手艺共同塑造了皮影戏的地域面貌。[来源：中国非遗网“不同地域皮影戏特点”](https://www.ihchina.cn/project_details/26209)

## 6. 剧目与民间生活

传统题材包括历史演义、神话传说、公案、战争、爱情和市井生活等。熟悉的故事进入皮影舞台后，会通过影人的动作、唱腔和音乐重新呈现。[来源：中国非遗网《中国皮影戏》](https://www.ihchina.cn/Article/Index/detail?id=11504)

皮影戏既用于娱乐，也曾服务于仪式、婚丧等社区活动；艺人中既有专业从业者，也有农闲时演出的业余艺人。理解皮影戏，需要把它放回具体的村落、节庆和观众生活中。[来源：UNESCO 中国皮影戏资料](https://ich.unesco.org/doc/src/17331-EN.pdf)

## 7. 非遗身份与传承

- **国家级非遗**：皮影戏属于传统戏剧类，项目编号为 **Ⅳ-91**；2006 年首批国家级非遗名录已包含相关地方项目。名录中不同地方项目有各自的申报地区与保护单位。[来源：皮影戏（华阴老腔）项目页](https://www.ihchina.cn/art/detail/id/13403.html)
- **联合国教科文组织名录**：中国皮影戏于 **2011 年**列入人类非物质文化遗产代表作名录。[来源：UNESCO 中国名录页](https://ich.unesco.org/en/state/china-CN)

保护工作不仅涉及影人实物，也涉及剧本、地方唱腔、操纵技艺和演出实践。中国非遗网项目介绍曾指出，现代影视娱乐的冲击、观众与演出市场减少，使部分皮影戏面临传承困难；这是该资料记录的背景，不应直接当作所有地区在整理日期的现状。[来源：皮影戏（华阴老腔）项目页](https://www.ihchina.cn/art/detail/id/13403.html)

## 8. 常用词与阅读提醒

| 词语 | 基础含义 |
| --- | --- |
| 影人、影偶 | 用于表演的人物形象或偶体。 |
| 影窗、亮子 | 演出中显现影像的幕面或相关装置的称呼。 |
| 主杆、手杆 | 唐山皮影中控制身体及手部动作的杆件名称。 |
| 影卷 | 唐山等地对皮影戏剧本的称呼。 |
| 砌末 | 演出使用的道具，如桌椅、器物等。 |

术语和用法具有地域性。上述词语可结合中国非遗网的[概述与唐山皮影介绍](https://www.ihchina.cn/art/detail/id/18619.html)阅读。

初次看戏时，可以留意影人的走路、转身和打斗怎样完成，演唱如何区分人物，以及锣鼓怎样配合动作。搜集后续资料时，建议同时记录地区、戏班、艺人、剧目和拍摄时间，方便比较不同传统。
