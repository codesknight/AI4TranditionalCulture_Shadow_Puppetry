## 皮影动作展示 Demo

直接在浏览器中打开 [demo/index.html](demo/index.html)，无需安装依赖或连接外部服务。

当前版本是「光影游乐场」：自由搭戏台，或在 75 秒内对齐五幕青色目标影子。达到 86% 匹配度并保持 0.65 秒即可过关；通关有时间奖励，最佳成绩仅保存在本机。

- 拖动戏台上的左手签、主签和右手签，或使用滑杆控制手臂与身体。
- 选择挥袖招手、信步登场、俯身行礼、拱手亮相与舒袖起舞，支持播放、暂停与归位。
- 调整灯光、动作速度，切换操纵杆显示；手柄获得焦点后可用方向键微调。
- 手机支持触摸拖动与上下排列的操作面板。
- 光源、影幕、影偶、三根签杆为独立对象，可分别选择和编辑；灯位、幕距和影偶离灯距离会改变投影。
- 调整灯光柔度与色调、影幕材质，每根签杆可独立调长度和显隐。
- `A/D` 移动，`W` 跳跃，`F` 转身，`Q/E` 调左手、`O/P` 调右手；页面也提供触屏快捷按钮。
- 挑战可暂停、重玩或退出；后台页面不计时。暂停时可以调整对象，继续后恢复判分。

影人为原创 SVG 风格化示意，关节、跳跃与点光源投影均为简化模型，不代表特定流派的传统程式。Demo 不含唱腔和音乐。

开发检查与静态打包（推荐 Node.js 22，CI 使用该版本）：

```bash
npm ci
npm run verify
```

运行时无需依赖；`npm ci` 安装的 Prettier 仅用于开发期格式检查。`verify` 包含格式、语法与本地资源检查、测试、构建。需要格式化时运行 `npm run format`。

打包结果位于 `dist/`。也可在仓库根目录运行 `python -m http.server 8765`，访问 `http://localhost:8765/demo/`。测试覆盖动作几何和主要控制逻辑，不替代浏览器视觉与触摸验证。新增动作在 `demo/core/actions.js` 注册，详见架构设计。
